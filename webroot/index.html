规则源

每条订阅都能单独设置地址、更新时间和启停。转换结果写入 config/rules/， 由内核启动时加载 —— 这里的增删改会自动重建索引并重载内核。
带「内置」标记的源随模块下发，可以停用，不能删除。

自定义 hosts

域名 → IP 的固定映射，优先级高于订阅解析。格式与系统 hosts 一致： IP 域名 [域名…]，0.0.0.0 域名 表示屏蔽。

自定义黑名单 / 白名单

黑名单：域名直接返回空地址（屏蔽）。白名单：只走国内解析组。一行一个域名。

日志

日志由内核按配置生成：服务日志需要 log-file，审计日志需要 audit-enable yes。服务起不来时先看「内核输出」。
